Region Check

Cihazın hedef ülkeden görünüp görünmediğini kontrol eder. VPN açıkken Safari'den aç.

Hazırlanıyor…

    Tarayıcıdan ölçülemeyenler (elle kontrol et)

    • SIM kart çıkarılmış / eSIM silinmiş
    • Location Services → OFF
    • Background App Refresh → OFF
    • Tracking → “Allow Apps to Request to Track” OFF
    • Bluetooth kapalı
    • Date & Time → Set Automatically OFF
    • Kayıt telefon numarasıyla değil, e-postayla

    IP bilgisi ipwho.is / ipapi.co üzerinden alınır. DNS sızıntısı tarayıcıdan ölçülemez.
